# Databased releases

Installers and the update feed for [Databased](https://github.com/svenbledt/databased-releases/releases), a database management app for Windows, macOS and Linux.

- **Installers** for each version are attached to that version's release.
- The **`feed`** release is read by the app to check for updates. Do not download from it by hand.

This repository holds release files only.
